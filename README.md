# 우리집 하루 (family-board)

아이들 요일별 스케줄·숙제를 정리해 아이가 스스로 확인하고,
부모는 픽업 담당과 서로의 일정을 조율하는 가족용 웹앱.

- 빌드 도구 없음 (Node.js 불필요) — HTML/CSS/JS 파일 그대로 동작
- 데이터는 Supabase (무료 플랜)
- 보호자는 이메일 로그인, 아이는 **전용 링크**로 로그인 없이 자기 화면만

```
family-board/
├─ prototype.html          화면 시안 (DB 없이 혼자 동작. 참고용)
├─ app/                    실제 앱  ← 이 폴더를 배포합니다
│  ├─ index.html
│  ├─ app.js
│  ├─ styles.css
│  ├─ config.js            ★ Supabase 주소·키를 여기에 넣습니다
│  ├─ manifest.json
│  └─ icon.svg
└─ supabase/
   ├─ 01_schema.sql        테이블·트리거·함수
   ├─ 02_policies.sql      접근 권한(RLS)
   └─ 03_seed.sql          우리 집 초기 데이터
```

---

## 설치 (30분이면 끝납니다)

### 1. Supabase 프로젝트 준비

1. [supabase.com](https://supabase.com) → 프로젝트 생성 (Region은 **Northeast Asia (Seoul)** 권장)
2. 좌측 **Authentication → Users → Add user** 로 보호자 계정을 만듭니다.
   - 이메일 / 비밀번호 입력, **Auto Confirm User 체크**
   - 엄마·아빠 각각 만들어도 되고, 하나만 만들어 같이 써도 됩니다.

### 2. SQL 실행

좌측 **SQL Editor** 에서 아래 순서대로 파일 내용을 붙여넣고 **Run**.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `supabase/01_schema.sql` | 테이블·트리거 생성 |
| 2 | `supabase/02_policies.sql` | 누가 무엇을 볼 수 있는지 설정 |
| 3 | `supabase/03_seed.sql` | 우리 집 초기 데이터 |
| 4 | `supabase/04_supplies.sql` | 준비물 체크리스트 |
| 5 | `supabase/05_reward_suggestions.sql` | 아이가 갖고 싶은 보상 제안 |

`03_seed.sql` 은 **맨 위 ▼설정▼ 블록을 먼저 고치세요.**

```sql
v_family_name  text := '우리집';
v_email_mom    text := 'mom@example.com';   -- ← 1번에서 만든 이메일
v_email_dad    text := null;                -- 아빠 계정 (없으면 null)
v_kid1_name    text := '지우';   v_kid1_desc text := '초4';
v_kid2_name    text := '하윤';   v_kid2_desc text := '초1';
```

실행하면 마지막에 **아이별 링크 토큰**이 표 형태로 나옵니다. 잠시 후 쓰니 복사해 두세요.
(나중에 앱의 `관리 → 가족 구성원 → 🔗 링크` 에서도 언제든 확인할 수 있습니다.)

### 3. 앱에 연결 정보 넣기

**Project Settings → Data API** 에서 두 값을 복사해 `app/config.js` 에 붙여넣습니다.

```js
export const SUPABASE_URL      = 'https://xxxxxxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

> `anon` 키는 공개되어도 되는 키입니다 (RLS가 막아줍니다).
> `service_role` 키는 **절대** 넣지 마세요.

### 4. 배포

`app` 폴더를 통째로 올리면 됩니다. 셋 중 아무거나:

- **Netlify Drop** — <https://app.netlify.com/drop> 에 `app` 폴더를 드래그. 계정 없이도 됩니다. 가장 빠름.
- **Vercel** — 계정 생성 후 폴더 업로드
- **Cloudflare Pages** — 무료, 직접 업로드 지원

> 파일을 더블클릭해서 `file://` 로 여는 방식은 **동작하지 않습니다.**
> ES 모듈과 Supabase 통신 때문에 `https://` 주소로 열어야 합니다.

### 5. 기기에 설치

| 대상 | 방법 |
|---|---|
| 엄마·아빠 폰 | 배포 주소 접속 → 로그인 → 브라우저 메뉴 **홈 화면에 추가** |
| 아이 태블릿 | `배포주소/#kid=<아이토큰>` 접속 → 자동으로 아이 화면 → **홈 화면에 추가** |

아이 링크는 한 번 열면 기기에 저장돼서, 이후에는 아이콘만 눌러도 자기 화면이 뜹니다.

## 쓰는 법

### 보호자 화면
| 탭 | 하는 일 |
|---|---|
| **오늘** | 담당 미정인 픽업 경고, 보상 승인 요청, 아이가 제안한 보상 검토, 아이별 숙제 진행률 |
| **주간** | 이번 주(지난주·다음주 이동 가능) 날짜별 시간표 |
| **가족일정** | 날짜별로 어른들 일정 + 픽업 담당 배정 |
| **관리** | 시간표·숙제·보상 등록, 예외 일정, 아이 링크, 포인트 규칙, 픽업 도우미 등록 |

### 아이 화면
- **오늘** — 시간표를 보고 학원 다녀오면 체크(+포인트), 숙제 체크(+포인트)
- **내 주간** — 내 시간표
- **포인트 상점** — 모은 포인트로 보상 교환 신청 (부모 승인 후 차감),
  갖고 싶은 보상 제안하기 (부모가 포인트를 정해 확정하면 상점에 추가됨)

### 핵심 개념 3가지

**1. 스케줄 세트**
"학기 중"과 "방학"처럼 시간표를 통째로 여러 벌 저장합니다.
각 세트에 적용 기간(1학기, 여름방학, 2학기 …)을 넣어두면 **날짜에 맞춰 자동으로 전환**됩니다.

**2. 이 날만 변경**
반복 시간표는 그대로 두고 특정 날짜에만 얹는 예외입니다.
- 하루 표시: 재량휴업일 / 현장학습 / 아픈 날 / 가족 일정
- 일정 취소: 학원 휴강 등
- 일정 추가: 병원, 생일파티 등

**3. 픽업 담당**
일정마다 "요일 기본 담당"(엄마 / 아빠 / 시터선생님 / 자율귀가)을 정해두고,
그날만 다르면 **가족일정 탭에서 그 날짜만** 바꿉니다. `↺` 로 기본값 복귀.
담당이 비어 있으면 빨간 **조율 필요** 배지가 뜹니다.

## 알아둘 점

- **동기화는 12초 간격 폴링**입니다. 아이가 체크하면 부모 화면에 늦어도 12초 안에 반영되고,
  화면을 다시 켜면 즉시 갱신됩니다. (WebSocket 실시간은 2차에서 붙일 수 있습니다)
- **푸시 알림은 아직 없습니다.** 알림은 앱 안의 🔔 알림함에만 쌓입니다.
  휴대폰 푸시는 서비스워커 + VAPID 키 + Edge Function 이 필요해 2차 작업으로 뺐습니다.
- **아이 링크 관리** — 링크를 아는 사람은 그 아이 화면을 볼 수 있습니다.
  유출이 걱정되면 `관리 → 구성원 → 🔗 링크 → 링크 새로 만들기` 로 기존 링크를 무효화하세요.
- 아이는 자기 일정·숙제·포인트만 볼 수 있고, **어른 일정은 보이지 않습니다.**
  포인트도 클라이언트가 아니라 DB 트리거가 계산하므로 임의로 늘릴 수 없습니다.

## 2차로 미뤄둔 것

- 휴대폰 푸시 알림 (숙제 미완료 리마인드, 픽업 담당 공란 알림 등)
- WebSocket 실시간 동기화
- 월간 달력 보기 / 포인트 사용 내역 통계
- 사진 첨부 (숙제 인증샷)
